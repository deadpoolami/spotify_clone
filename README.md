# 🌐 Basic HTML, CSS & JavaScript Project

This is a simple front-end web project built using **HTML**, **CSS**, and **JavaScript**.  
The project focuses on practicing core web development concepts such as layout design, styling, and basic interactivity.

---

## 📌 Features

- Clean and responsive UI  
- Structured HTML layout  
- Styled using CSS  
- Interactive functionality using JavaScript  
- Beginner-friendly and easy to understand code  

---

## 🛠️ Technologies Used

- **HTML5** – Structure of the web page  
- **CSS3** – Styling and layout  
- **JavaScript (ES6)** – Interactivity and logic
